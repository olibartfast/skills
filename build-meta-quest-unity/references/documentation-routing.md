# Unity Documentation Routing

Start with:

- Documentation index: <https://developers.meta.com/horizon/llmstxt/documentation/unity/llms.txt/>
- API index: <https://developers.meta.com/horizon/reference/unity/latest/index.md>

Search the documentation index for the exact capability and its setup, samples, requirements,
troubleshooting, and performance pages. Common topic families include Meta XR packages, OpenXR,
Interaction SDK, passthrough and mixed reality, hand/body/eye/face tracking, anchors, scene
understanding, avatars, spatial audio, platform services, rendering, and optimization.

Also consult when relevant:

- Design: <https://developers.meta.com/horizon/llmstxt/design/llms.txt/>
- Policies: <https://developers.meta.com/horizon/llmstxt/policy/llms.txt/>
- Distribution: <https://developers.meta.com/horizon/llmstxt/resources/llms.txt/>

Use `latest` to discover APIs, then reconcile results with `Packages/manifest.json`,
`Packages/packages-lock.json`, and the Unity editor version. Fetch full Markdown pages; do not
implement from index summaries alone.
