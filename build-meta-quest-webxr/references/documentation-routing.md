# Web and WebXR Documentation Routing

Start with:

- Meta web documentation:
  <https://developers.meta.com/horizon/llmstxt/documentation/web/llms.txt/>
- WebXR specifications: <https://www.w3.org/TR/webxr/>

Fetch current pages for Quest Browser capabilities, remote debugging, audio and video formats,
WebXR Media Layers, and Immersive Web SDK. When using Immersive Web SDK, retrieve the relevant
ECS, interaction, lifecycle, setup, and AI-assisted development pages from the Meta index.

Also consult when relevant:

- Design: <https://developers.meta.com/horizon/llmstxt/design/llms.txt/>
- Policies: <https://developers.meta.com/horizon/llmstxt/policy/llms.txt/>
- Distribution: <https://developers.meta.com/horizon/llmstxt/resources/llms.txt/>

Reconcile guidance with `package.json`, browser feature detection, response headers, and
on-device remote-debugging output. Fetch full pages rather than implementing from index
summaries.
