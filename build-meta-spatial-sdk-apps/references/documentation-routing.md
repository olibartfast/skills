# Spatial SDK Documentation Routing

Start with:

- Documentation index: <https://developers.meta.com/horizon/llmstxt/documentation/spatial-sdk/llms.txt/>
- API index: discover the pinned Spatial SDK release from
  <https://developers.meta.com/horizon/essentials/ai-solutions/>

Fetch the current pages for creating a new app or adding Spatial SDK to an existing 2D app,
hybrid apps, project configuration, entities and components, panels, input, lifecycle,
permissions, platform services, testing, and optimization.

Also consult when relevant:

- Android Apps: <https://developers.meta.com/horizon/llmstxt/documentation/android-apps/llms.txt/>
- Design: <https://developers.meta.com/horizon/llmstxt/design/llms.txt/>
- Policies: <https://developers.meta.com/horizon/llmstxt/policy/llms.txt/>
- Distribution: <https://developers.meta.com/horizon/llmstxt/resources/llms.txt/>

Spatial SDK API indices may not provide a `latest` alias. Use the release matching the Gradle
dependency, and fetch full pages rather than relying on index summaries.
